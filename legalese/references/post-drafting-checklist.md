# Post-Drafting Checklist

## 1. Register

- [ ] The selected register is identified.
- [ ] Every obligation, permission, prohibition, and remedy matches the register.
- [ ] Valid higher-register provisions remain.
- [ ] Decorative archaism is absent.

## 2. Enumeration

- [ ] Every item in a series has an independent legal vector.
- [ ] Synonyms that share one vector are collapsed.
- [ ] Settled legal classes replace repeated instance lists.
- [ ] Distinct legal domains remain separate.

## 3. Finality

- [ ] Each termination phrase appears once.
- [ ] Equivalent finality phrases do not recur.
- [ ] Prospective and retroactive effects remain distinct.
- [ ] Partial and total invalidity remain distinct.

## 4. Operative units

- [ ] Each clause has one primary command, grant, prohibition, trigger, or consequence.
- [ ] Independent duties are in separate units.
- [ ] Triggers precede consequences.
- [ ] Exceptions immediately qualify their rule.

## 5. Advantage and evasion

- [ ] No actor can obtain through an agent what the actor cannot obtain directly.
- [ ] No alternate instrument bypasses the rule.
- [ ] No procedural route defeats the substantive prohibition.
- [ ] No drafting ambiguity rewards prohibited conduct.

## 6. Supremacy

- [ ] The instrument's rank is identified.
- [ ] The conflict trigger is explicit.
- [ ] The affected scope is explicit.
- [ ] The consequence is explicit.
- [ ] The survival rule is explicit.
- [ ] The claim stays within lawful authority.

## 7. Closed ecosystem

- [ ] Every defined term is used consistently.
- [ ] Every cross-reference resolves.
- [ ] Established definitions are not paraphrased.
- [ ] Identical concepts use identical terms.
- [ ] External instruments are named only when authorized.

## 8. Severability

- [ ] Standard and Formal instruments use ordinary severability.
- [ ] Sovereign and Archaic instruments protect essential sovereign intent when required.
- [ ] Severance consequences are explicit.
- [ ] Remaining provisions have a survival rule.

## 9. Hostile reading

Test:

- direct action
- indirect action
- agent or nominee action
- alternative instrument
- conflicting authority
- delayed action
- partial performance
- waiver or consent
- invalidity or repeal
- procedural bypass

Close every verified loophole within scope. Report unresolved conflicts to the user.

## 10. Structural fidelity

- [ ] User wording is unchanged unless the user approved a revision.
- [ ] Locked structure is unchanged.
- [ ] Numbering and hierarchy match the controlling instrument.
- [ ] Approved changes do not alter unrelated text.
- [ ] Definitions and cross-references remain synchronized.

## 11. Economy

- [ ] Every word carries legal effect, structure, or necessary context.
- [ ] Redundant adverbs are removed.
- [ ] Synonym stacks are removed.
- [ ] Recitals do not repeat operative provisions.
- [ ] Rationale and drafting narration are absent from operative text.

## 12. Exact final read

- [ ] Read the complete final instrument.
- [ ] Verify names, dates, numbers, thresholds, parties, offices, and jurisdiction.
- [ ] Verify every source-dependent proposition.
- [ ] Verify the exact final fixed-page artifact when one exists.
- [ ] Correct any conflict between the validation record and the artifact.
