# Skills

Personal agent skills repository for Kibocha Solutions.

This repository contains reusable operating guidance extracted from project
references without project-specific residue.

## Current status

- Repository scaffold: `tools/scaffold-skill.py`
- Active skills:
  - `documentation`: documentation drafting, Writerside-compatible technical
    documentation, and comment guidance
  - `legalese`: legal drafting across plain-language to sovereign registers
  - `technical-diagrams`: Draw.io-based technical diagram production and QA
  - `ci-cd`: Git workflow, commit cleanup, CI pipelines, deployment, and
    rollback guidance. This skill controls this repo's Git and commit
    conventions.
  - `docx`, `pdf`, `pptx`, `xlsx`: file-format skills for Office and PDF work
  - `frontend-design`: distinctive frontend implementation guidance
  - `webapp-testing`: Playwright-based local web application testing
  - `communications`: external correspondence (default) and internal update
    guidance, gated by confirmed audience
  - `doc-coauthoring`: structured interactive workflow for co-authoring a
    document with the user (context gathering, refinement, reader testing)
  - `mcp-builder`: guide for building new MCP servers (Python/TypeScript)
  - `discernment-nudge`: appends targeted follow-up questions after a
    substantive answer, once per conversation, inviting the user's own
    scrutiny of facts/reasoning/missing context
  - `skill-creator`: create, evaluate, and improve local skills
  - `graphify`, `maestro`, `bootstrap`, `system-init`, `system-design`,
    `ssh`: repo/session infrastructure and planning support
- Primary documentation target: JetBrains Writerside-compatible docs
- Project references remain source material, not a second instruction authority
