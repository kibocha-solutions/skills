# CSO Document Rules

## Activation

Apply this reference to documentation work in CSOs.


## ANCEM and SOP punctuation

1. In files under `ANCEM/` or `SOP/`, use a U+2014 em dash only in a Chapter or Article title or as a list chapeau replacing a colon.
2. Do not use a U+2014 em dash anywhere else in those files.
3. Rewrite the sentence when removing a prohibited dash.
4. Do not replace a prohibited dash with punctuation that preserves the same defective construction.

## Proposal formatting

1. Apply the donor's template when one exists.
2. Apply the following settings when no controlling template exists.

| Element | Formatting |
|---|---|
| Body text | 12 pt, black, justified |
| Heading 3 | 12 pt, black, left-aligned, bold |
| Heading 2 | 14 pt, black, left-aligned |
| Heading 1 | 16 pt, black, left-aligned, uppercase |
| Tables | Black text; left-aligned; grey fill only when a fill is used |

3. Use headings that name the section.
4. Do not use promotional or website-style proposal headings.
