# Letterhead and Pagination

## Apply this reference

Use these rules for Word, PDF, printed slides, and other fixed-page outputs.

## Page setup

1. Apply the controlling template.
2. Use 0.5-inch header and footer margins when no template or user instruction specifies another value.
3. Keep footer content consistent across equivalent pages.
4. Suppress a folio only where the numbering rules require it.

## Page flow

1. Flow body content to fill the available page area.
2. Remove a wide unused gap between the final body paragraph and the footer margin.
3. Permit natural short space on title, cover, signature, and execution pages.
4. Inspect the exact rendered page before accepting the flow.

## Tables

1. Keep the heading row with at least two data rows at the first page break.
2. Move the table start to the next page when that minimum does not fit.
3. Repeat the heading row on every continuation page.
4. Keep each row readable and free of clipping.
5. Inspect the final row and the page after every table break.

## Images

1. Keep each image whole.
2. Move an image to the next page when it does not fit.
3. Scale an image proportionally when it exceeds the full content area.
4. Do not crop or split an image unless the user requests it.

## Letterhead

1. Put the full letterhead on page 1.
2. Put a reduced identity band on continuation pages.
3. Keep the organization name and optional document title or reference code in the continuation band.
4. Keep the logo, full address, contact details, and registration details off continuation pages unless the template requires them.

## Numbering

### Documents with front matter

1. Suppress the visible folio on the cover page.
2. Count the cover as roman numeral i.
3. Show lowercase roman numerals from physical page 2 through the end of front matter.
4. Restart at Arabic numeral 1 on the first substantive page.
5. Show the numeral 1 on that page.

### Documents without front matter

1. Suppress the visible folio on page 1.
2. Show Arabic numbering from page 2 onward.

## Final procedure

1. Freeze the source.
2. Regenerate the fixed-page artifact.
3. Render every page to an image.
4. Inspect headers, footers, folios, flow, tables, images, and final-page balance.
5. Correct the source.
6. Restart from source freeze.
7. Record the final artifact hash when the artifact is released.
8. Do not patch generated Word or PDF files.
